# Natural Language Processing (NLP) Project

## 📌 Project Overview

This project demonstrates fundamental Natural Language Processing (NLP) techniques using Python. It explores text processing and linguistic analysis through a text about the role of flowers in human language and culture.

## 🔍 Implemented Techniques

- **Sentence Segmentation:** Splitting text into individual sentences.
- **Word Tokenization:** Breaking text into individual words.
- **Word Frequency Analysis:** Identifying the most frequently used words.
- **Stop-word Removal:** Removing standard English stop words and custom stop words.
- **N-gram Analysis:** Extracting and analyzing unigrams, bigrams, and trigrams.
- **POS Tagging:** Identifying grammatical categories of words (nouns, verbs, adjectives, etc.).
- **Named Entity Recognition (NER):** Detecting and classifying named entities.
- **Date Extraction:** Identifying different date formats using Regular Expressions (Regex).
- **Word Information:** Extracting word stems, lemmas, definitions, examples, synonyms, and antonyms.

## 🛠️ Technologies Used

- Python
- NLTK
- spaCy
- PyDictionary
- Regular Expressions (Regex)

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install the required libraries:
   ```bash
   pip install nltk spacy PyDictionary
   ```

3. Download the spaCy English model:
   ```bash
   python -m spacy download en_core_web_sm
   ```

4. Open `projet.ipynb` using Jupyter Notebook or Google Colab.

5. Run the cells sequentially.

The objective of this project is to understand and apply essential NLP techniques, from basic text preprocessing to advanced linguistic analysis and information extraction.
